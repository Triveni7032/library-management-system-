# Library Management System

A Python-based Library Management System developed as a console application. This project demonstrates Python modules, classes, functions, exception handling, and basic library operations.

## Features

- Add new books
- View all books
- Search for a book
- Add library members
- View all members
- Issue books to members
- Return books
- Handle invalid user input and errors
- Prevent duplicate book and member IDs
- Check book availability

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- Python Modules
- Exception Handling
- Functions
- Lists
- Loops and Conditions
